Indian Bank Logos

Free CDN & JSON API for 96 RBI scheduled commercial banks. Standard and horizontal PNG logos — use in any frontend, no auth required.

96 banks 192 PNG logos CDN + REST API npm: indian-bank-logos

API Endpoints

GET /api/banks — list all banks
GET /api/banks?q=hdfc — search by name or slug
GET /api/banks?category=private — filter by category
GET /api/banks/hdfc-bank — single bank

npm Package

npm install indian-bank-logos
import { searchBanks, getLogoUrl, getBanksByCategory } from "indian-bank-logos";

searchBanks("axis");
getBanksByCategory("nationalised");
getLogoUrl("hdfc-bank");
// => https://indian-bank-logos.vercel.app/logos/hdfc-bank.png
